# MVP 系统测试方案（量化版）

> 项目：知行职业学院排课选课教务协作 AI 智能体系统 ｜ 版本 V1.0 ｜ 2026-11-06
> 范围：正常、边界、对抗、权限、故障五类场景，共 19 项接口级用例 + 30 条评测集回归。

## 一、测试环境与判定口径

- 环境：本机试点部署 http://127.0.0.1:8000；LLM key 为占位符（同时用于验证故障降级路径）。
- 客户端：Python urllib（UTF-8）；知识库 4 份文档；种子账号 scheduler/quality/director/counselor。
- 判定口径：HTTP 状态码 + 业务错误码信封（code 字段）双重断言；业务码以 body 为准。

## 二、场景与用例清单（量化）

| 场景 | 用例数 | 用例明细 | 通过标准 |
| 正常 | 4 | 登录签发JWT / 知识库列表=4文档 / 新建会话 / 聊天SSE事件流 | 全部 code=0，SSE 事件序列完整 |
| 边界 | 4 | 错误口令(code=1006) / 异常方法(405) / 无效会话ID(code=1002) / 超长2001字(code=1003) | 业务码拦截 + 中文提示，无 500 |
| 对抗 | 2 | 提示词注入+违规意图提问 / 审计高风险标记核验 | risk_flag=1 且审计可见；红线兜底话术 |
| 权限 | 4 | 无token(1005) / 辅导员越权知识库(1005) / 辅导员越权审计(1005) / 质量专员正向(code=0) | 未授权一律 1005，授权正常 |
| 故障 | 1 | LLM 不可用降级 | 中文兜底文案，不崩溃不挂起 |
| 评测回归 | 30 | evaluation/qa_cases.json（知识库10/工具调用10/违规5/多轮5） | 填入真实 key 后批量回归 |

## 三、通过标准与统计

- 单场景通过标准：该场景全部用例判定“通过”。
- 总体通过标准：19/19 项通过 + 评测集回归率 ≥ 90%（30 条）。
- 实测结果：19/19 通过（LLM 相关回答以兜底事件验证降级，完整回答待真实 key）。
