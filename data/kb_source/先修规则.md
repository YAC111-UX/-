# 知行职业学院 课程先修规则（2024 版）

> 说明：本文件为原型阶段示例数据，用于验证 RAG 检索流程；试点前须替换为教务处发布的正式先修规则文档。

## 一、先修关系总表

| 课程代码 | 课程名称 | 先修课程 | 先修要求 |
|---|---|---|---|
| SW101 | 程序设计基础 | 无 | — |
| SW102 | Web 前端开发基础 | 无 | — |
| SW201 | 数据库原理与应用 | SW101 程序设计基础 | 需取得 60 分及以上 |
| SW202 | 数据结构 | SW101 程序设计基础 | 需取得 60 分及以上 |

| SW401 | 岗位实习 | SW302 软件项目实训 | 需考核合格 |

## 二、先修冲突处理

1. 未满足先修要求的课程，选课系统将直接阻断并提示缺失的先修课程。
2. 先修课程正在重修且预计当学期结课的，可由学生提出书面申请，经专业课程负责人审核、排课专员确认后允许跨先修选课；该情形属于人工审核，系统不做自动放行。
3. 先修课程成绩为缓考待出分的，可先行选课，成绩公布后未达标的自动转入人工处理队列。
4. 新旧课程代码并存期间，先修关系按官方映射表折算后判断，不得以代码不同为由认定无先修冲突。

## 三、常见问题

- 问：我这门课有没有先修限制？
  答：请对照本规则"先修关系总表"逐条核对；系统在选课前会前置校验并给出冲突提示。
- 问：先修课挂科了还能选后续课程吗？
  答：不能。须重修取得 60 分及以上，或按第二条款申请人工审核。
